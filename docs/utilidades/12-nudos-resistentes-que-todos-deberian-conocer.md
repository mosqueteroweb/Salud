# 12 nudos resistentes que todos deberían conocer



## Los 12 nudos

**1. Nudo para cerrar bolsas de líquido**
Sella bolsas de plástico con líquido de forma hermética, sin derrames al girar la bolsa.
<video controls preload="none" src="../video/nudos-lifehaxx/01-bolsa-liquido.mp4">Vídeo 1</video>

**2. Nudo de esquina para lonas**
Asegura las esquinas de carpas o lonas (tarps) tensándolas con firmeza.
<video controls preload="none" src="../video/nudos-lifehaxx/02-esquina-lona.mp4">Vídeo 2</video>

**3. Nudo de remolque**
Atado a un gancho metálico, para tracción y remolque de objetos pesados.
<video controls preload="none" src="../video/nudos-lifehaxx/03-remolque.mp4">Vídeo 3</video>

**4. Nudo para haz de leña**
Enrolla y enhebra cuerda alrededor de ramas para transportar leña suelta.
<video controls preload="none" src="../video/nudos-lifehaxx/04-haz-lena.mp4">Vídeo 4</video>

**5. Nudo para transportar botellas**
Lleva dos botellas juntas de forma segura y equilibrada.
<video controls preload="none" src="../video/nudos-lifehaxx/05-transportar-botellas.mp4">Vídeo 5</video>

**6. Nudo para cerrar sacos**
Cierre fuerte y fácil para sacos o bolsas.
<video controls preload="none" src="../video/nudos-lifehaxx/06-cerrar-sacos.mp4">Vídeo 6</video>

**7. Nudo para atar verduras**
Sujeta manojos de verduras o hierbas sin dañarlas.
<video controls preload="none" src="../video/nudos-lifehaxx/07-atar-verduras.mp4">Vídeo 7</video>

**8. Nudo de reparación de cuerda**
Repara cuerdas rotas con agarre duradero y resistente.
<video controls preload="none" src="../video/nudos-lifehaxx/08-reparacion.mp4">Vídeo 8</video>

**9. Nudo para colgar y organizar**
Mantiene cuerdas y sogas ordenadas; ideal para colgar.
<video controls preload="none" src="../video/nudos-lifehaxx/09-colgar-organizar.mp4">Vídeo 9</video>

**10. Nudo de escape**
Para situaciones críticas; puede salvar la vida en emergencias.
<video controls preload="none" src="../video/nudos-lifehaxx/10-escape.mp4">Vídeo 10</video>

**11. Nudo de conexión (unir cuerdas)**
Une dos cuerdas; usado en escalada o rescate (seguridad para la vida).
<video controls preload="none" src="../video/nudos-lifehaxx/11-conexion.mp4">Vídeo 11</video>

**12. Nudo de lazo deslizante**
Lazo ajustable libremente; útil para múltiples aplicaciones de colgado.
<video controls preload="none" src="../video/nudos-lifehaxx/12-lazo-deslizante.mp4">Vídeo 12</video>
