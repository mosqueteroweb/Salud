# Truco 9 — Trazar con linterna de móvil


Noveno truco del recopilatorio "Daily Useful Tips". Usa la linterna del móvil para proyectar la imagen de un libro sobre una hoja de papel y poder trazar el dibujo.

## Qué ves en el clip
- Teléfono móvil con linterna encendida.
- Se proyecta la imagen de un libro sobre una hoja.
- Se traza el dibujo sobre el papel.

## Para qué sirve
Copiar/ampliar dibujos de un libro con luz de fondo, sin escáner ni impresora.
